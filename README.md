# Smart Food Expiry Tracker and Waste Reduction System

## About
A Python-based project that helps users manage food inventory, track expiry dates, and reduce food waste.

## Features
- Add, view, search, and delete food items
- Identify expired and soon-to-expire items
- Record food waste and estimate its cost
- Generate inventory analytics
- Export reports to CSV
- Save data using JSON file handling

## Technologies
- Python
- Object-Oriented Programming (OOP)
- JSON
- Exception Handling
- CSV

## How to Run
1. Install Python 3.
2. Download `main.py` from this repository.
3. Open the file in Python IDLE.
4. Run the module using F5.

## Purpose
To help households and small shops monitor food expiry dates and reduce avoidable food waste.
